# Brand provenance

## Supplied kit

The project owner supplied `bellows-brand-kit-v2.zip` on 2026-10-30 for
integration into `smeltery/bellows`, using Popcorn's brand integration as the
reference. The archive contains 57 files under `bellows-brand-kit-v2/`.
Those files are preserved byte-for-byte in this directory, with the enclosing
archive folder removed. Integration documentation and `checksums.json` are
repository additions.

Archive SHA-256:

```text
cca2aa09646080151818b773d62d201d5d8e127772f1f569b8c1e1878cffcaa8
```

The supplied guide and tokens describe a proposed revision. The repository now
uses its banner and light/dark lockups; the original proposal labels and
`2.0-proposal` token version remain intact as part of the supplied material.
The documentation header is a design concept, and its command specimens are
authored examples rather than captured run output.

## Artwork and references

The original [handoff](START-HERE.txt) describes deterministic vector artwork
with outlined lettering. The kit contains no generated mascot artwork, and no
new artwork or font conversions were produced for this integration. The supplied
SVGs and PNGs are retained as separate masters and exports; no regeneration
script was included.

The handoff records these reference snapshots:

- [Bellows](https://github.com/smeltery/bellows/tree/42997255cf14e36cd171fa8bd47dcae84963e933):
  product description and documented command examples.
- [Popcorn](https://github.com/smeltery/popcorn/tree/b5b02fe6baff61e7391c0d1f9d9b352094edb03b/assets/brand):
  completeness of the identity handoff, including variants, tokens, fonts,
  provenance, and applications. The supplied notes state that no Popcorn artwork
  is included.

Artwork is integrated at the project owner's request. The archive does not
include a separate artwork license or author grant; this record does not assert
one. The repository's existing [license](../../LICENSE) is unchanged.
